# DESIGNER — Selskapstype (Norge)

**Beslutning (anbefalt):** Start som **ENK** kun hvis du må validere raskt med nær null kostnad. Gå til **AS** før Drop 01 tar betalt pre-order i skala — premium merke + begrenset ansvar + tillit.

## Sammenligning

| | **ENK** | **AS** |
|---|---|---|
| Ansvar | Personlig (hele formuen) | Begrenset til aksjekapital |
| Oppstart | Raskt, billig | Stiftelse + min. aksjekapital 30 000 NOK |
| Tillit (premium drop) | Svakere | Sterkere overfor kunder/fabrikker |
| MVA | Samme terskel | Samme |
| Vipps / bank | OK | Ofte enklere B2B |
| Skatt | Overskudd som personinntekt | Selskapsskatt + utbytte |
| Anbefaling | Waitlist / RFQ-fase | **Før betalende Drop 01** |

## Anbefalt sti
1. **Nå:** Registrer ENK *eller* gå direkte til AS hvis seed er klar.
2. **Før Drop 01 checkout med betaling:** **AS** på plass (org.nr i vilkår, Stripe/Vipps på selskap).
3. Regnskapsfører fra første faktura/fabrikkdepositum.

## Locked for planen
- Selskapsland: **Norge**
- Målform: **AS før betalende drop** (ENK kun midlertidig validering)
