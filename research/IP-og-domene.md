# DESIGNER — IP- og domenesjekk (desktop)

**Dato:** 2026-08-27  
**Status:** Foreløpig research — ikke juridisk binding. Bekreft hos Patentstyret / EUIPO-agent før søknad.

## Varemerke: ordet «DESIGNER»

| Risiko | Vurdering |
|---|---|
| Distinktivitet | **Høy risiko.** «Designer» er beskrivende/generisk på engelsk for klær (klasse 25). EUIPO avviser ofte rene ordmerker som mangler særpreg (Art. 7(1)(b)/(c) EUTMR). |
| Kollisjon | Mange treff forventes på «DESIGNER» / «THE DESIGNER» i mote. Full TMview/EUIPO-søk må kjøres av agent. |
| Anbefaling | Ikke stol på rent ordmerke alene. |

### Registreringsstrategi (anbefalt)

1. **Primært:** Figurativt merke / wordmark — distinktiv typografi for **DESIGNER** (logo som varemerke).
2. **Sekundært:** Ordsammensetning med mer særpreg, f.eks. **DESIGNER DROP**, **ATELIER DESIGNER**, **DESIGNER LOOP** (test søkbarhet).
3. **Norge:** Søknad til Patentstyret (klasse 25 + evt. 35 nettbutikk).
4. **EU:** EUTM via EUIPO når logo er fryst — eller start NO og utvid.
5. **Bruk:** ™ på materialer nå; ® først etter registrering.
