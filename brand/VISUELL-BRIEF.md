# DESIGNER — Visuell brief, fargekort og mønsterregler

**Drop 01 kapittel:** *Ochre Band* / *Lime Band*  
**Formel:** `Minimal silhuett + begrenset flate + bold accent + smart refleks`

## Moodboard-retning (ord)

| Lag | Referanse | Hva vi tar | Hva vi ikke tar |
|---|---|---|---|
| Silhuett | Pas Normal Off-Race, rolig techwear | Rene linjer, få paneler | Race-neon, sponsor-look |
| Fargeenergi | [Vlisco](https://vlisco.com) Super-Wax / Sky Wax | Mettede accentfarger, kontrast, luksus-signal | All-over wax print, figurative klisjeer |
| Teksturidé | Wax crackle / bubble marks | Subtil tekstur i print eller refleks | Bokstavelig batik-kostyme |
| Kontekstfoto | Karbon landevei, by-edge, café etter tur | 80k-sykkel i bilde uten prislapp | Watt/Strava-skjermer |

## Mønsterregler (DESIGNER Motif Family v1)

**Navn:** *Band Geometry* — abstraherte bånd/buer inspirert av wax-print grafikk, ikke figurative motiver.

1. Én motivfamilie per drop-kapittel.
2. Maks **én** accent-sone per plagg (baklomme-panel ELLER mansjett ELLER sidestripe).
3. Jersey: maks ett bånd eller bakpanel; resten solid.
4. Ingen all-over print i drop 1.
5. Motivet tegnes originalt for DESIGNER — **ingen Vlisco-assets**.
6. Refleks skal **gjenbruke samme geometri** (samme kurver/linjer).

### Plasseringskart
```
Loop Shirt:  [solid body] + [rear pocket panel OR cuff band] + [reflect hem]
Jersey:      [solid body] + [rear pocket band OR side stripe] + [reflect hem/pocket edge]
Bib:         [solid] + [gripper accent color] + [reflect rear thigh]
```

## Typografi / wordmark
- Ordet **DESIGNER** er hero-signal (landing + hangtag).
- Ekspressiv grotesk eller hybrid display — **ikke** Inter/Roboto/Arial/system.
- Tracking litt åpen; versaler ok på hangtag.
- Størrelse på plagg: diskret nakke/hem — merket snakker via farge/motiv, ikke brystlogo.

## Foto-regler (drop-teaser)
